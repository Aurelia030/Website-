# Aurelia Apartments – Version 13

Gesicherte Website mit Deutsch als Standard sowie Englisch und Spanisch.

## Lokal ansehen

Auf GitHub **Code → Download ZIP** wählen, ZIP entpacken und `standalone/Aurelia-Apartments-13.html` per Doppelklick im Browser öffnen. Bilder und Schriften sind in dieser Datei enthalten. Externe Inhalte und das Tally-Formular brauchen Internetzugang und werden erst nach Aktivierung geladen.

## Bei STRATO bereitstellen

Nur `index.html` und den vollständigen Ordner `assets/` gemeinsam in das für die Domain bestimmte Verzeichnis hochladen. Vorher eventuell vorhandene Website sichern. Die Dateien im Verzeichnis `standalone/` werden für STRATO nicht benötigt. Die vorhandene WordPress-Installation nicht ungeprüft überschreiben.
